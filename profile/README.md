# Emsisoft Emergency Kit - A Portable Second-Opinion Scanner

## Why a Kit Instead of an Install

A PC that is already misbehaving is a bad place to stack another full security suite on top of a broken one. The Emergency Kit runs from a directory you choose. You update it, scan, quarantine, and then leave it or remove the folder. The installed product, if there is a healthy one, keeps the real-time job. If there is no healthy one, the kit buys you a scan before you reinstall Windows, which is often the real remediation.

"Second opinion" means a different engine looking at the disk, not a second product enabled forever. Two real-time scanners on one desktop fight over files and slow the machine. One real-time product plus an on-demand kit when you are suspicious is a calmer split.

## What You Run

| Piece | Role |
|---|---|
| Command-line or GUI scanner | Walks the paths you select |
| Definition update | Pulls a current set before you trust the result |
| Quarantine | Holds detections until you know the PC still boots |
| USB copy | Lets you start on a PC whose browser is not a safe place to download anything else |
| Log | The artifact you keep after the folder is gone |

Update before a scan you intend to believe. An old kit on a dusty stick will miss a family that did not exist when the stick was made, and it will still look official.

## Scan Choices

A quick scan of running processes and common locations is a first look. A full scan is the one you want when a PUP keeps returning or a download folder is the suspected source. Scanning an entire secondary disk of videos takes hours and rarely answers a browser hijack. Point the long scan at the system volume, the user profile, and the folder where the unwanted installer landed.

Close the obvious malware's window if you can, and do not keep using the infected browser to "test" during the scan. Let the kit finish. Then reboot if a detection was a driver or a service.

## Steps

1. Copy the kit from a PC you trust, or update it before you carry the stick.  
2. On the target, allow the update if the network is safe enough to use.  
3. Scan the system volume and the user profile.  
4. Read paths before you quarantine a security tool you installed yourself.  
5. Quarantine the rest and reboot.  
6. If the same detection returns, plan a reinstall rather than a third scanner.

## Who It Is For

Technicians who want a portable scanner on the tool drive. A household PC whose trial antivirus expired and whose browser is full of extras. A poor fit as a permanent shield: when the visit is over, install a maintained real-time product or reinstall the OS. A poor fit for a disk that is failing. Scanning is a heavy read. Copy personal files off a dying disk before you make the kit walk every sector.

## Requirements

| Item | Expectation |
|---|---|
| OS | Windows versions the kit currently supports |
| Rights | Administrator |
| Disk | Space for definitions and quarantine |
| Network | For the update; offline scans only with a set you already refreshed |
| Trust | The stick itself must come from a clean machine |

## Fixes

The update fails. The network is filtered or the PC's clock is wrong. Fix the clock and try a known network before you trust an offline stale scan.  
A known-good tool is quarantined. Restore it and scan that folder as an exception only after you confirm the file.  
The scan is clean and the symptom remains. The cause may be a malicious site, a browser notification, or a compromised account. A clean disk scan does not reset a stolen password.  
The kit will not start. Another security product blocks the portable executable. Run it with that product's allow procedure or from a simpler environment.  
Detections return immediately. Something relaunched them. Look at startup and other users, then prefer a reinstall if the chain is unclear.

## After the Scan Leaves

The log and the quarantine are the parts worth keeping when you delete the portable folder. A clean PC a week later does not need the kit resident. A PC that is still showing the same detection needs the log, not a second brand of scanner started in a hurry. Install a maintained real-time product or plan a reinstall if the kit only buys a temporary quiet hour.

Update the stick from a healthy machine before the next visit. A kit that has not been updated in months will still open and will still miss families it has never heard of. The scan finishing is not the same as the definitions being current.

| Keep | Throw away later |
|---|---|
| The log of what was quarantined | The idea that the kit is now the antivirus |
| The stick, updated next time | A second full suite installed on top |
| A plan if detections return | Another on-demand pass the same afternoon |
